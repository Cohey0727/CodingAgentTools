# Google Calendar Integration

When the user asks about schedules, events, meetings, appointments, or calendar-related topics (e.g., "today's schedule", "what's on my calendar", "schedule a meeting", "free time this week", "add an event"), ALWAYS use the Google Calendar MCP tools.

## Available MCP Tools

- `list-calendars` - List all calendars
- `list-events` - List events (supports date range filtering)
- `search-events` - Search events by keyword
- `get-event` - Get event details
- `create-event` - Create a new event
- `update-event` - Update an existing event
- `delete-event` - Delete an event
- `get-freebusy` - Check free/busy availability
- `get-current-time` - Get current time in a timezone
- `respond-to-event` - Accept/decline invitations
- `list-colors` - List available event colors
- `manage-accounts` - Manage connected Google accounts

## Keywords that trigger calendar tools

Japanese: 予定, スケジュール, カレンダー, 日程, 会議, ミーティング, 空き時間, 予約
English: schedule, event, meeting, calendar, appointment, free time, availability
