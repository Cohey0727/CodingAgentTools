# 2026-10-03 — pi 1.0

pi が 0.87.1 から 1.0.0 に上がった（間に 0.99.0〜0.99.2 がある）。0.99 で
MCP が pi 本体に入り、`~/.pi/agent/mcp.json` は pi に組み込まれた MCP の
設定ファイルになった。このレポが入れる `pi-mcp-adapter`（5.0.0）は自分の
設定を `~/.pi/agent/mcp-adapter.json` から読み、`mcp.json` の `imports` は
読まない。

`make pi-global` は OpenCode の MCP サーバーを読ませる
`"imports": ["opencode"]` を `mcp.json` に書いていた。そのため pi を起動する
たびに次の警告が出る。`mcp-adapter.json` が無い環境では、pi から MCP サーバーが
1 つも見えない。

```
~/.pi/agent/mcp.json: pi-mcp-adapter does not read imports in this file; move them into ~/.pi/agent/mcp-adapter.json.
```

## レポの対応

- `bin/pi-global-models.sh`（`make pi-global`）— `opencode` の import を
  `~/.pi/agent/mcp-adapter.json` に書くようにした。`mcp.json` には書かない。
  `mcp.json` に残った `imports` は `mcp-adapter.json` に移し、ほかに何も
  残らなければ `mcp.json` を消す。
- README の pi パッケージと MCP の節を pi 1.0 に合わせた。

組み込みの MCP は OpenCode の設定を import できない。`configs.jsonc` の
`opencode.overrides.mcp` を両方の CLI の一覧にしておくため、
`pi-mcp-adapter` を使い続ける。

## pi 1.0 で変わったこと

- `pi-mcp-adapter` 5.0.0 は、pi に組み込まれた MCP を置き換える。初回起動時に
  `~/.pi/agent/settings.json` の `extensions` へ `"-builtin:mcp"` を書き、
  その旨を一度だけ通知する。`/mcp` は adapter のパネルを開く。
  `pi mcp add` で `mcp.json` に足したサーバーも adapter が読む。
- TUI が既定でフルスクリーンになった。従来のスクロールバックに戻すなら、
  `~/.pi/agent/settings.json` に `"tuiMode": "regular"` を足す（1 回だけなら
  `pi --tui-mode regular`）。
- `--model` なしの `--provider` はエラーになった。以前は黙って無視され、
  別の provider の既定モデルで動いていた。
- 起動時に `@tintinweb/pi-subagents` について
  `Host-provided extension packages must be declared in peerDependencies ...`
  という警告が出る。0.99.0 で pi に足された検査で、引っかかっているのは
  パッケージ側。最新の 0.19.0 でも出るが、動作には影響しない。

## 既存チェックアウトの手順

```bash
git pull
make setup    # pi を 1.0.0 に、pi パッケージを最新に上げ、make pi-global も流す
```

`make pi-global` が `mcp.json` の `imports` を `mcp-adapter.json` に移す。
`mcpServers` など、ほかのキーは `mcp.json` に残り、adapter がそこから読む。
`imports` だけだった `mcp.json` は消える。

## 確認

```bash
pi --version                       # 1.0.0
pi list                            # pi-loop / pi-goal / pi-mcp-adapter / pi-subagents
cat ~/.pi/agent/mcp-adapter.json   # imports に "opencode"
```

`pi` を起動して、次を確かめる。

- `pi-mcp-adapter does not read imports in this file` の警告が出ない。
- フッターに `MCP: 2 servers enabled` が出て、`/mcp` に `playwright` と
  `parallel-search` が並ぶ。
- 2 回目以降の起動で、`~/.pi/agent/settings.json` の `extensions` に
  `"-builtin:mcp"` が入っている。
