# ask-mmx — MiniMax への問い合わせ

このマシンには `claudemmx` (`/Users/kohei/.local/bin/claudemmx`) が入っている。これは MiniMax をバックエンドにした Claude Code 互換 CLI で、`-p/--print` で非対話の一発質問ができる。Claude Code (このセッション) から別 LLM (MiniMax) の意見を取るための「セカンドオピニオン」ツールとして使う。

## MiniMax の特徴

- **ハルシネーションが少ない**: 事実関係の検証・裏取り・「Claude の回答が捏造を含んでいないか」のクロスチェックに向く
- **高速に動作する**: 応答が速いため、軽量なセカンドオピニオンや反復的な問い合わせを気軽に投げられる

これらの特性から、**事実確認 (ファクトチェック)** や **素早い別系統チェック** が必要な場面で特に有用。

## いつ使うか

- **セカンドオピニオン**: Claude が出した結論にバイアス・見落としがないか別系統 (MiniMax) で検証したい
- **コードレビュー**: Claude が書いた diff に別モデルの観点でレビューを得たい
- **意見交換**: 設計判断・ライブラリ選定・アルゴリズムの妥当性などで他モデルの見解が欲しい

逆に **使わないほうがいい**: 単純な質問・自分で十分判断できる作業・既に並列の Claude agent / codex を回している場合 (重複)。

## 基本コマンド

### 非対話で一発質問する (主用途)

```bash
claudemmx -p "ここに質問やレビュー依頼を書く"
```

- `-p` / `--print` = 非対話のワンショット実行。stdout に最終回答が出る
- 複雑なプロンプトはヒアドキュメントで安全に渡す:

```bash
claudemmx -p "$(cat <<'EOF'
<質問本文>
EOF
)"
```

- 標準入力からプロンプトを渡す場合:

```bash
cat prompt.md | claudemmx -p
```

回答をファイルに残したいときはリダイレクトする:

```bash
claudemmx -p "..." > /tmp/mmx-answer.md
```

## Claude Code から呼ぶときの定型パターン

### パターン A: セカンドオピニオン (反対意見を求める)

```bash
claudemmx -p "$(cat <<'EOF'
私 (別 AI) は以下の方針で実装しようとしている。これに反対する立場で論点を出してほしい。
盲点・見落とし・代替案を遠慮なく指摘してほしい。

# 背景
<タスクの背景>

# 提案中の方針
<Claude の結論>

# 制約
<制約条件>
EOF
)"
```

ポイント:
- **反対意見を明示的に求める** (同意を求めると追従しがちなので)
- **役割を明示** (「別 AI からのレビュー依頼」と書くと真面目に検証してくれる)

### パターン B: diff レビュー

```bash
claudemmx -p "$(cat <<EOF
以下の diff を 1) ロジックバグ 2) エッジケース漏れ 3) テスト不足 4) 命名 の観点でレビューして。

\`\`\`diff
$(git diff)
\`\`\`
EOF
)"
```

結果を見て Claude 側で対応の要不要を判断する。MiniMax の指摘を鵜呑みにせず、根拠を確認すること。

### パターン C: 設計判断の突き合わせ

```bash
claudemmx -p "$(cat <<'EOF'
以下の 2 案で迷っている。トレードオフを整理し、推奨案とその理由を述べてほしい。

## 案 A
<内容>

## 案 B
<内容>

## 評価軸
- 保守性
- パフォーマンス
- 実装コスト
EOF
)"
```

## 注意

- **MiniMax の指摘を盲信しない**: あくまでセカンドオピニオン。最終判断は Claude (このセッション) が行う
- **長時間ブロックする可能性**: 回答に時間がかかることがある。Bash の `timeout` 引数を伸ばすか、長い質問は `run_in_background: true` で投げる
- **秘匿情報**: プロンプトは MiniMax (外部) に送られる。社外秘・秘密鍵・個人情報を含めない
- **書き込みさせない**: 意見を聞くだけなら `-p` の非対話モードを使い、ファイル変更を伴うフラグ (`--allow-dangerously-skip-permissions` 等) は付けない
