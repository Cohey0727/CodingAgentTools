# speech — 文章の読み上げ

引数の文章を [Kokoro-82M](https://huggingface.co/hexgrad/Kokoro-82M)（82M パラメータの TTS モデル）で音声にし、その場でスピーカーから再生する。音声ファイルは残さない。

## 実行

このスキルのディレクトリにある `speak.py` に文章を渡す:

```bash
<このスキルのディレクトリ>/speak.py "読み上げる文章"
```

- 再生が終わるまで戻らない。長い文章では Bash の timeout を延ばす
- 初回だけ、依存（約 850MB）とモデルのダウンロードで数分かかる。2 回目以降は 1〜2 秒で喋り始める
- MLX で動くので Apple Silicon の Mac 専用。`uv` が要る

## 渡す文章の整え方

かな・漢字を 1 文字でも含めば日本語ボイス（`jf_alpha`）、含まなければ英語ボイス（`af_heart`）で読む。モデルは書かれた文字をそのまま読むので、渡す前に読み上げ用に直す:

- 日本語の文中の英字はカタカナにする。英字のままだと崩れる（「Claude Code」→「ラウデオ」、「OK」→「う」）。「クロードコード」「オーケー」と書けば正しく読む
- Markdown の記号・コードブロック・URL・表は読ませず、言葉に言い換えるか省く
