# 請求書 PDF の生成

受け取った請求データを所定フォーマットの請求書 PDF にする。
数量（稼働時間）の算出方法はこのスキルの関知外 — 数字はユーザーまたは呼び出し元の会話から受け取る。
日別の稼働明細も渡された場合は、**freelance-work-record スキル**で稼働実績 PDF もあわせて生成する。

## 前提

- 発行者情報（氏名・登録番号・住所・TEL・メール・振込先・出力先）は同ディレクトリの `personal-config.json` から読む（**git 管理外**。無ければ `personal-config.example.json` をコピーしてユーザーに記入を依頼して終了）
- デザインは `templates/invoice.html` に固定。レイアウト変更の依頼がない限りテンプレートは編集しない
- PDF 化は Chrome ヘッドレスを使う

## Step 1: 入力の収集

会話・引数から以下を確定させる。不足があればユーザーに確認する:

| 項目 | デフォルト |
|---|---|
| 請求先（〜御中） | なし（必須） |
| 対象年月 | 前月 |
| 品目名 | `開発費用（YYYY年M月分）` |
| 数量（時間） | なし（必須）。15 分 = 0.25 の小数表記（74:30 → 74.5時間） |
| 単価 | なし（必須） |
| 発行日 | 対象月の翌月 1 日 |
| 請求書番号 | 発行日ベースで `YYYYMM01-1` |
| 支払期限 | 発行月の月末 |

## Step 2: HTML 生成 → PDF 化

`templates/invoice.html` の `{{PLACEHOLDER}}` を置換して作業ディレクトリ（scratchpad）に HTML を書き、
Chrome ヘッドレスで PDF 化する:

```bash
"/Applications/Google Chrome.app/Contents/MacOS/Google Chrome" \
  --headless --disable-gpu --no-pdf-header-footer \
  --print-to-pdf="<output_dir>/<請求書番号>_請求書.pdf" invoice.html
```

### 命名規則

- 出力は `<請求書番号>_請求書.pdf`。稼働実績（freelance-work-record スキル）とペアで出すときは同じ請求書番号 prefix で揃える（`<請求書番号>_稼働実績.pdf`）

### 金額計算

- 小計 = 数量 × 単価、消費税 10%、合計 = 小計 + 消費税
- `{{SUBTOTAL}}`・`{{TAX}}`・`{{TOTAL_INCL_TAX}}` は 3 桁カンマ区切り
- 数量を変更したら 小計 / 消費税 / 合計 / ご請求金額 / 10%対象 をすべて連動して更新すること

## Step 3: 検証と送付

1. 生成した PDF を Read で開いて確認する: 1 ページに収まっているか、数量 × 単価 = 小計・税計算が正しいか、罫線や文字の折り返しが崩れていないか
2. 問題なければ SendUserFile で送付

## よくある調整依頼

- **数量の変更**: 金額 5 箇所（小計 / 消費税 / 合計 / ご請求金額 / 10%対象）を連動更新
- **別請求分の控除**: 一部の時間を別請求書で請求済みの場合、稼働実績はそのままにして請求書の数量だけ減らす（例: 77.5 − 5 = 72.5時間）
